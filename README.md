## Τι είναι αυτό

Ένα μη επανδρωμένο εναέριο όχημα που χάνει το GPS σε αποστολή έρευνας και διάσωσης πρέπει να
συνεχίσει να εκτιμά πού βρίσκεται. Η εργασία αντιμετωπίζει αυτό ως **πρόβλημα ανάκτησης θέσης**
και το απαντά με **στατιστικά τεκμηριωμένη σύγκριση πολλαπλών οικογενειών μεθόδων στα ίδια
δεδομένα** - βαθιά μάθηση, κλασική μηχανική μάθηση, φίλτρο Kalman, εκτίμηση αβεβαιότητας και
ενισχυτική μάθηση - με κριτήριο το **σφάλμα αλυσιδωτής ανακατασκευής τροχιάς** και όχι την
απώλεια εκπαίδευσης. Σε επίπεδο σμήνους, τρεις οικογένειες μεθόδων ανάλυσης γράφων προβλέπουν
την **κατάτμηση του δικτύου** όταν οι πιστευόμενες θέσεις αποκλίνουν.

Το αποθετήριο περιέχει **τον κώδικα, τα δεδομένα αποτελεσμάτων, τις αναλύσεις και τα
εκπαιδευμένα μοντέλα πίσω από κάθε αριθμό της εργασίας**, μαζί με το τελικό κείμενο.

Το κεντρικό μεθοδολογικό εύρημα: **καλύτερη απώλεια επικύρωσης δεν σημαίνει καλύτερη πλοήγηση.**
Αυτό επιβεβαιώθηκε επανειλημμένα - το GBT νικά το LSTM σε αλυσιδωτό σφάλμα παρά χειρότερη
απώλεια παραθύρου, και το batch 256 δίνει καλύτερη απώλεια αλλά 41% χειρότερο αλυσιδωτό σφάλμα.

## Κύρια αποτελέσματα

Σφάλμα αλυσιδωτής ανακατασκευής σε κρατημένο τμήμα πτήσης 12,5 s, 5 ανεξάρτητες αρχικοποιήσεις
ανά στοχαστικό μοντέλο, 95% διαστήματα εμπιστοσύνης κατανομής t:

| Μοντέλο | Τελικό σφάλμα (m) | 95% ΔΕ |
|---|---|---|
| **Transformer** | **9,10** | [2,61–15,60] |
| SSL-Transformer | 13,99 | [8,83–19,16] |
| GBT | 18,56 | [16,87–20,24] |
| RandomForest | 26,42 | [25,76–27,08] |
| LSTM | 29,68 | [24,82–34,53] |
| SSL-LSTM | 34,57 | [31,50–37,64] |
| EKF (κλασικό) | 132,47 | ντετερμινιστικό |
| Καθαρή αδρανειακή ολοκλήρωση | 143,00 | ντετερμινιστικό |

**«Ποιο είναι το καλύτερο» έχει τέσσερις απαντήσεις**, γιατί είναι τέσσερα διαφορετικά ερωτήματα:

| Κριτήριο | Απάντηση | Τιμή |
|---|---|---|
| Καλύτερος ακατέργαστος αριθμός | Ensemble 5 αρχικοποιήσεων Transformer | **3,92 m** |
| Καλύτερη στατιστικά τεκμηριωμένη | Transformer | 9,10 m |
| Πλέον αξιόπιστος αριθμός | RandomForest (διακύμανση 2%) | 26,42 m |
| Επιλογή πραγματικής ανάπτυξης | LSTM, επιλεγμένη αρχικοποίηση | 24,78 m |

Άλλα ευρήματα, αναφερόμενα όπως βγήκαν:

- Το **GBT** - τυφλό ως προς τη χρονική σειρά - πιάνει το 3ο καλύτερο σφάλμα με **~1/70** του
  κόστους εκπαίδευσης του Transformer.
- Η **αυτο-επιβλεπόμενη προεκπαίδευση δεν βελτίωσε καμία από τις δύο αρχιτεκτονικές.** Αρνητικό
  αποτέλεσμα, επιβεβαιωμένο σε 5 αρχικοποιήσεις.
- Ο Transformer είναι το **λιγότερο προβλέψιμο** μοντέλο (σχετική διακύμανση ±71%, αρχικοποιήσεις
  από 3,22 ως 15,04 m) - γι' αυτό δεν είναι το μοντέλο ανάπτυξης.
- **Σμήνος:** χειροποίητα τοπολογικά χαρακτηριστικά **Macro-F1 0,841** [0,831–0,852], υψηλότερο
  από Node2Vec (0,780), GIN (0,789) και GCN (0,722) - με στατιστική σημαντικότητα μόνο έναντι GCN.
- Η **κεφαλή αβεβαιότητας** βαθμονομείται ασθενώς (r = 0,203) και η διόρθωση δύο φάσεων δεν
  βοήθησε (r = 0,199).
- Το **RL** έμαθε να μικραίνει τη διόρθωση υπό αβεβαιότητα (0,116 → 0,093 m/s σε ελεγχόμενη
  δοκιμή) χωρίς να κυριαρχεί στον διαθέσιμο προϋπολογισμό εκπαίδευσης.

## Ακεραιότητα δεδομένων

Κάθε αριθμός σε αυτό το αποθετήριο υπολογίστηκε **μετά** τη διόρθωση τριών σφαλμάτων διαρροής και
ενός σφάλματος εγκυρότητας συνόλου δεδομένων. Κανένα προγενέστερο αποτέλεσμα δεν αναφέρεται:

1. **Ανακάτεμα παραθύρων πριν τον διαχωρισμό** - γειτονικά επικαλυπτόμενα παράθυρα μοιράζονται
   9 από 10 χρονικά βήματα. Διόρθωση: αυστηρά χρονικός, διαδοχικός διαχωρισμός.
2. **Κανονικοποίηση πριν τον διαχωρισμό** - ο `StandardScaler` προσαρμοζόταν σε όλο το σύνολο.
   Διόρθωση: προσαρμογή μόνο στο τμήμα εκπαίδευσης.
3. **Μόλυνση κλίμακας μεταξύ πηγών** - Διόρθωση: Δ ανά πηγή, όρια πηγής στα παράθυρα, και ένα
   μόνιμο φράγμα (`verify_unit_consistency()`) που μπλοκάρει αυτόματα ασύμβατους συνδυασμούς.
4. **Το `uav_navigation_dataset.csv` δεν είναι πραγματική τροχιά** - απορρίφθηκε μόνιμα.

## Γρήγορη εκκίνηση

```bash
pip install -r ai_backend/requirements.txt

# Έλεγχος της ζωντανής λογικής ανάκτησης - χωρίς Godot, χωρίς δίκτυο
python ai_backend/api/recovery_orchestrator.py

# Διαδραστική επίδειξη αποστολής (απώλεια GPS → ανάκτηση → επιστροφή στη βάση)
python ai_backend/live_mission_demo.py
python ai_backend/live_mission_demo.py --model Transformer   # οποιοδήποτε από τα 7 μοντέλα

# Επίδειξη σμήνους με ζωντανή πρόβλεψη κατάτμησης
python ai_backend/live_swarm_demo.py

# Ζωντανός UDP server για τη σκηνή Godot
python ai_backend/api/udp_server.py
```

Η αναπαραγωγή της εκπαίδευσης χρειάζεται τα ακατέργαστα δεδομένα - βλ. [`DATA.md`](DATA.md).
Πλήρεις οδηγίες: [`EXECUTION_GUIDE.md`](EXECUTION_GUIDE.md).
