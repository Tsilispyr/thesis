# `runs/` - Pipeline Output (Generated, Not Hand-Authored)

Everything in this folder is produced by
`../ai_backend/ml_pipeline.py` - safe to delete and regenerate by rerunning
that script (`python ai_backend/ml_pipeline.py` from `AI_Recovery/`, ~12 min
on CPU). Nothing here should be hand-edited.

| File / folder | What it is |
|---|---|
| `figures/*.png` | The 12 analysis charts from the pipeline's 12 steps (dataset audit, cleaning, normalization, feature correlations, sequence window, Runs A-D training curves, all-runs comparison, RL evaluation, summary dashboard). Overwritten every run. |
| `models/*.pth` | One model checkpoint per pipeline run (`A_nav_nonorm`, `B_nav_norm`, `C_imu_norm`, `D_nav_imu_norm`) - experiment artifacts from the pipeline's internal ablation, distinct from `../ai_backend/models/`'s production checkpoints. |
| `results.json` | All numerical results, appended per run under a `run_N` key (never overwritten) - the source data for `analysis_report.html`/`.docx`. |
| `run_counter.json` | `{"count": N, "last_run": "..."}` - how many times the pipeline has been run. |
| `pipeline.log` | Appended full console output of every run, with a `RUN #N` header. |
| `analysis_report.html` / `.docx` | Self-contained report generated by `../generate_analysis_report.py`, embedding all 12 figures - open directly in a browser or Word, no server needed. Regenerate after each pipeline run. |

## Important caveat

**Older entries in `results.json`/`pipeline.log` (anything before the fixes
documented in `AI_RECOVERY_EXECUTION_PLAN.md` §7-§10) reflect bugs that have
since been fixed** - a train/val leakage bug, a domain-shift scaler-
contamination bug, and a scaler-fit-before-split bug all silently inflated
how good earlier runs looked. Check the run's date/index against the
execution plan before citing any historical number from this folder. Rerun
the pipeline fresh if you need a number you can actually trust.
